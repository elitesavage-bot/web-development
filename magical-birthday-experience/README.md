# Magical Birthday Experience

A cinematic interactive anniversary experience created for Nourine. It includes the quest sequence, companion creature, dragon encounter, animated music equalizer, Happy Birthday melody, uploaded memory video, and final HAPPY ANNIVERSARY reveal.

## Source

This directory is an exported source snapshot from the Replit project. The existing files at the repository root are preserved.

## Included

- React + Vite source in src/
- Responsive memory video in public/nourine-birthday-memory.mp4
- Vite, TypeScript, and component configuration

## Running in the original workspace

The app is part of the original Replit pnpm workspace and uses that workspace dependency catalog.
